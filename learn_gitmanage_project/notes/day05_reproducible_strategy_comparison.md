# Day 5：学会可复现地比较

## 1. 实验目标

按照学习路线，本日完成以下任务：

- 建立固定测试种子，让不同策略面对相同的初始位置与目标。
- 记录每回合是否成功、最终距离和执行步数。
- 区分“曾进入目标范围”和“最后停在目标范围内”。
- 将逐回合结果保存为 CSV。
- 统计成功回合数、总回合数和成功率。
- 本日不训练任何网络，重点练习可复现的实验记录与比较。

## 2. 实验设置

| 参数 | 设置 |
|---|---:|
| 目标位置（TARGET） | 5.0 |
| 比例增益（Kp） | 0.2 |
| 最大动作绝对值（MAX_ACTION） | 1.0 |
| 每回合最大步数（MAX_STEPS） | 25 |
| 测试种子 | 0–9，共 10 个 |
| 随机扰动范围 | [-0.05, 0.05] |
| 目标容差 | 距离目标小于 0.1 |
| 策略 | open_loop、closed_loop |

### 公平性控制

1. 两种策略使用相同的测试种子，因此每个 seed 对应相同的初始位置。
2. 每个 seed 使用 `random.Random(seed + 10000)` 预先生成 25 步扰动序列。
3. 开环与闭环在相同 seed 下使用同一组逐步扰动。
4. 每回合均执行完整的 25 步，不因提前进入目标范围而停止，以便观察策略是否会在之后离开目标范围。

环境状态更新为：

```python
position = position + action + disturbance
```

动作会先经过裁剪，限制在 `[-1.0, 1.0]` 范围内。

## 3. 策略说明

### 3.1 开环策略（open_loop）

开环策略根据当前步数，从预先设定的动作序列中读取动作，不根据执行过程中的当前位置修正动作。

本次实验使用的参考动作序列为：

```python
REFERENCE_ACTION_SEQUENCE = tuple(
    1.0 * (0.8 ** i) for i in range(25)
)
```

**注意：** 该序列是本次实验中人为构造的参考动作序列，并非从 Day 4 实际成功轨迹中提取的回放数据。因此，本次结果评价的是这组预设动作序列在当前测试场景中的表现，不能据此概括所有开环策略的性能。

### 3.2 闭环策略（closed_loop）

闭环策略每一步读取当前位置，并根据当前位置与目标位置之间的误差计算动作：

\[
e_t = x_{\text{target}} - x_t
\]

\[
u_t = K_p e_t
\]

其中本次实验设置 `Kp = 0.2`。动作随后经过最大幅值裁剪。

## 4. 评价指标

| 字段 | 含义 |
|---|---|
| `strategy` | 使用的策略 |
| `seed` | 测试随机种子 |
| `initial_position` | 初始位置 |
| `target` | 目标位置 |
| `ever_reached` | 本回合是否曾进入目标容差范围 |
| `first_reached_step` | 首次进入目标范围的步数；未进入则为空 |
| `final_position` | 第 25 步执行后的最终位置 |
| `final_distance` | 最终位置到目标的绝对距离 |
| `final_success` | 最终位置是否处于目标容差范围 |
| `steps_executed` | 本回合实际执行步数 |

成功判据：

```python
abs(target - position) < 0.1
```

本实验特别区分：

- `ever_reached`：过程中至少有一次进入目标范围。
- `final_success`：完整执行 25 步后，最终位置仍在目标范围内。

## 6. 结果分析

### 6.1 开环策略

开环策略有 7/10 回合曾经进入目标范围，但最终成功为 0/10。

这说明“曾经经过目标附近”并不等于“最终能够停留在目标附近”。开环策略按照预设序列继续执行动作，无法根据当前位置和已经发生的扰动主动调整后续动作。

例如 Seed 6：

- 初始位置：3.966700
- 首次进入目标范围：第 1 步
- 最终位置：8.812787
- 最终距离：3.812787
- 最终成功：否

该回合很早经过目标位置，但之后继续执行预设动作，最终离目标较远。

### 6.2 闭环策略

闭环策略在 10/10 回合最终成功，平均最终距离约为 0.035841。

闭环控制每一步根据当前位置重新计算误差和动作。随着位置接近目标，误差减小，控制动作也随之减小，因此在当前环境和参数设置下，能够较稳定地停留在目标容差范围内。

例如 Seed 0：

- 初始位置：4.222109
- 首次进入目标范围：第 7 步
- 最终位置：5.044636
- 最终距离：0.044636
- 最终成功：是

### 6.3 为什么开环首次到达更快，却没有最终成功？

开环策略的预设动作在部分回合中较快经过目标，但它不根据当前误差减小动作，也不根据扰动重新规划动作。闭环策略会随着误差缩小而减小动作，因此首次进入目标范围可能更晚，但最终定位结果更好。

因此，不能只用首次到达步数判断策略优劣；还需要结合最终距离和最终成功率评价。

## 7. 实验结论

在本次一维位置控制环境、当前参数与测试场景下：

1. 开环策略最终成功率为 0%，闭环策略最终成功率为 100%。
2. 开环策略有 7 次曾进入目标容差范围，但 10 次最终均未停留在目标范围内。
3. 闭环策略 10 次均最终处于目标容差范围内。
4. 闭环策略的平均最终距离约为 0.035841，明显小于开环策略的 2.415054。
5. 本实验展示了反馈控制在当前场景中对初始状态差异和逐步扰动的修正作用。

**结论范围：** 以上结论只针对本次使用的环境、动作序列、控制参数、扰动范围和测试种子。开环策略使用的是人为构造的参考序列，不是 Day 4 的实际成功轨迹，因此不能将本次结果推广为“所有开环控制都不如闭环控制”。
