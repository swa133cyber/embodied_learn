# Day 04：开环与闭环控制

## 1. 核心概念

**开环控制（Open-loop Control）**

不根据执行过程中的实际状态调整动作，按照预先设定的指令执行。

**闭环控制（Closed-loop Control）**

持续获取系统状态，根据当前状态与目标之间的误差重新计算控制动作。

## 2. 成功案例

实验条件：
- 起点：0
- 目标：5
- 控制方式：闭环控制

实验结果：
- 最终位置：4.982
- 动作数量：38

将这次产生的动作序列从相同起点回放，最终位置仍为 4.982。

结论：在初始条件和执行过程一致的理想环境中，固定动作序列可以重复成功。

## 3. 失败案例

实验条件：
- 原始起点：0
- 新起点：1
- 目标：5
- 控制方式：回放原始动作序列

实验结果：
- 最终位置：5.982
- 最终误差：约 0.982

结论：初始状态发生变化后，原来的动作序列不一定仍然适用。

## 4. 外部扰动案例

假设运动过程中受到向后 0.5 个单位的外部扰动：

- 开环：继续执行原动作，最终误差约为 0.5。
- 闭环：根据新的状态重新计算动作，在控制能力足够的情况下可以恢复到目标附近。

## 5. 今日总结

开环控制不主动根据执行结果修正动作，适用于环境和执行条件较为确定的任务。

闭环控制利用状态反馈修正误差，能够应对一定程度的初始状态变化和外部扰动。

真实机器人通常需要结合开环规划与闭环反馈，而不是简单地只使用其中一种。
